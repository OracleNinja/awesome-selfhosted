# Integration Proof

This file was authored by a confined ecc-worker agent running inside an
isolated git worktree. The worker's writes were restricted by a
PreToolUse confinement hook to that worktree only, and the worker had
no Bash access and could not run, commit, or push anything itself.

It reached the working branch only after the Lead reviewed and
approved the change.
